# Bot de WhatsApp - Municipalidad de Posadas  

Este proyecto es un bot de WhatsApp desarrollado para la Municipalidad de Posadas, con el objetivo de mejorar la comunicación y brindar información relevante a los ciudadanos a través de la plataforma de mensajería.

## Funcionalidad  

El bot permite a los usuarios interactuar con la Municipalidad de Posadas mediante mensajes de WhatsApp, ofreciendo respuestas automáticas a consultas frecuentes sobre el Codigo de Edificacion tales como: trámites, normativas, y otras consultas relacionadas con la edificación en la ciudad, información sobre servicios municipales, horarios de atención, noticias y eventos locales, entre otros.
